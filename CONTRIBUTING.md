# Como contribuir

Obrigado por querer melhorar o Cofre do Lobo.

## Antes de enviar uma sugestão

- Pesquise se já existe uma issue sobre o assunto.
- Explique o problema e o resultado esperado.
- Não inclua senhas, e-mails reais, frases de recuperação ou HTMLs pessoais exportados.

## Pull requests

1. Faça um fork do repositório.
2. Crie uma branch com nome claro, por exemplo `melhoria-icones`.
3. Mantenha o projeto em um único arquivo HTML quando a mudança exigir código.
4. Preserve o design aprovado: cores, fontes, espaçamentos, animações, efeitos neon, cards, rodapé e identidade visual não devem ser modificados sem autorização explícita do mantenedor.
5. Teste a abertura offline e a exportação antes de enviar.
6. Descreva no pull request o que foi alterado e como foi testado.

## Ideias bem-vindas

- Melhorias de acessibilidade.
- Correções de compatibilidade em navegadores.
- Melhorias de segurança revisáveis.
- Traduções e documentação.
