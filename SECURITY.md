# Política de Segurança

## Escopo

O Cofre do Lobo processa informações sensíveis localmente. Relatos de vulnerabilidades relacionados à criptografia, exportação, recuperação, vazamento de dados ou execução indevida de código são prioridade.

## Como reportar uma vulnerabilidade

Não publique detalhes sensíveis em uma issue pública antes de a correção existir.

1. Abra uma issue com o título **[SEGURANÇA] Solicitação de contato privado** e sem detalhes técnicos sensíveis; ou
2. Use o canal de contato que o mantenedor informar no perfil do GitHub.

Inclua, quando possível:

- descrição objetiva do problema;
- passos seguros para reproduzir;
- impacto potencial;
- versão do arquivo testada;
- sugestão de correção, se houver.

## Boas práticas para quem usa

- Não compartilhe a senha mestre, frase de recuperação ou HTML exportado com dados.
- Baixe o projeto apenas deste repositório e confira o hash SHA-256 publicado em Releases.
- Abra o HTML em navegador atualizado.

## Aviso

O projeto busca boas práticas de segurança, mas nenhum software deve ser tratado como garantia absoluta. Faça backups e avalie o código antes de guardar informações importantes.
